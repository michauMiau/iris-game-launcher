# Game compatibility

## Known working (verified)

| Title | Notes |
|---|---|
| **Bonelab** (Unity OpenXR) | Works, requires HandsStuck mod, only the Steam version got the patch, Fusion broken, use FusionHelper or a different networking layer |
| **Boneworks** (Unity Oculus integration, SDK 1.43, `Data/Plugins/OVRPlugin.dll`) | Works via OVRPlugin shim → LibRevive64 (OpenVR) → SteamVR under Proton (SteamVR + HMD required for a VR session) |
